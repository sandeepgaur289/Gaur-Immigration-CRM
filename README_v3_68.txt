GAUR CRM v3.68 — Enrollment Filters & Client Search

Enrollment Payment Report now supports:
• Company-wise filter.
  - MD: All / Smart Choice / White Wave.
  - GM: automatically locked to own company.
• Assistant Manager-wise filter.
  - GM sees own-company AMs.
  - MD sees AMs from both companies.
• Client search by:
  - Client Name
  - Mobile Number
  - Passport Number
  - Lead ID
  - Case ID
• Partial search is supported.
• Filters can be combined, e.g. Smart Choice + Gurpreet Kaur + mobile/name search.
• Clear button resets all filters.
• Matching result count is shown.
• Passport number is displayed in the enrollment row when available.

All v3.67 safe Enrollment routing and existing bank/payment/proof functionality remain intact.

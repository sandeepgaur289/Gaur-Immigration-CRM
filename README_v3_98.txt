GAUR CRM v3.98 — Daily Lead Report

New dedicated report:
• Report Date selector (defaults to today).
• Company-wise Smart Choice / White Wave lead uploads.
• Uploaded Rows and actual New Lead records are shown separately.
• Active new leads and leads moved to Bin are shown.
• AM-wise allocation report shows how many leads were allocated to each AM on that date.
• Allocation uses allocation_history, so it reports the actual allocation actions performed that day.
• A secondary table shows current active leads whose latest assigned_at is on that date.
• Upload file detail shows file, total rows, new, duplicates, invalid, uploader and time.
• MD can view Both / SCIC / WWIC.
• GM is automatically restricted to own company.
• Print / Save PDF is dedicated to the report page.
• True .xlsx export has Summary, AM Allocation and Import Files sheets.
• WhatsApp Share creates a clean text summary.

Lead Allocation now has a direct "Daily Lead Report" button.

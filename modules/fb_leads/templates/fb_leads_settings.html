🚀 Setup Guide (5 Steps)

Meta App banao
developers.facebook.com/apps → Create App → Business type choose karo.
Lead Ads Testing Tool se Form ID lo
Lead Ads Testing Tool → apna Page select karo → Form select karo → URL mein form ID copy karo. Ya Form Library mein jaao: Ads Manager → Tools → Instant Forms.
Page Access Token generate karo
Graph API Explorer → apna app select karo → Generate User Token → Page Token exchange karo. Phir .env mein set karo:
FB_PAGE_ACCESS_TOKEN=EAAxxxxxxxxxxxxx
Agar alag pages hain SCIC/WWIC ke liye toh neeche form mein individual tokens de sakte ho.
Webhook configure karo (Real-time ke liye)
Meta App Dashboard → Webhooks → Page → Subscribe karo.
Callback URL:
{{webhook_url}}
Verify Token:
{{verify_token}}
Phir leadgen field subscribe karo. .env mein set karo:
FB_WEBHOOK_VERIFY_TOKEN={{verify_token}}
FB_APP_SECRET=your-meta-app-secret
Neeche form mein Form ID + Company add karo
Har Facebook Lead Form ek company se map karo (SCIC ya WWIC). Done! Leads automatically aati rehni chahiye.

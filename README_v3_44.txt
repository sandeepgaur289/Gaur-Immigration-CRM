GAUR CRM v3.44 — EDITABLE CLIENT RECORDS

Implemented:
• Every linked client in GM/MD Client Ledger now has a dedicated ✏️ Edit button.
• Edit opens the SAME AM-maintained Lead/Client record.
• Editable fields: Client Name, Contact No., Country/Program, Visa Type, Client Status, Follow-up Date, Remarks.
• If the client is already enrolled, the linked Client Case is synchronized automatically.
• No duplicate client record is created.
• Every edit writes an entry into Lead Activity History with user and timestamp.
• AM remains the source of client/lead details; GM/MD can correct/update the same record.

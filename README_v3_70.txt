Day-wise calculation:
• Today's Enrollment = enrollment_date is today's date.
• Today's Revenue = ONLY payment actually received today:
  - 1st Payment if 1st Payment Date/Time is today.
  - 2nd Payment if 2nd Payment Date/Time is today.
  - Other Payment if Other Payment Date/Time is today.
• Package amount is NOT counted as revenue.
• A client enrolled yesterday but paying today contributes only to today's revenue.
• A client enrolled today with payment pending contributes only to today's enrollment count.

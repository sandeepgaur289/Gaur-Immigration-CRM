GAUR CRM v3.39 — VOICE + BIRTHDAY CELEBRATION

NEW BIRTHDAY SYSTEM
• Reads Date of Birth from Employee Master records.
• On the employee's birthday, every logged-in portal receives the celebration.
• Shows employee photo, name, designation and company branding.
• Full-screen confetti celebration.
• Plays a locally synthesized Happy Birthday melody.
• Speaks a personalized birthday wish using the browser's available voice.
• Runs on login and checks every 60 seconds.
• Shows each employee birthday once per browser session/day to avoid repeated popups.
• Supports Smart Choice and White Wave.

ENROLLMENT SYSTEM
• Existing v3.38 enrollment celebration remains intact.
• Enrollment photo/name/client/amount celebration continues across portals.

IMPORTANT BROWSER NOTE
Some browsers block audio until the user has clicked/interacted with the page once.

DEPLOYMENT
Deploy this app.py/ZIP to Railway as the next version and restart the service.

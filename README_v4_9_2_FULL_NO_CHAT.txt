THE GAUR CRM v4.9.2 — FULL CRM / NO CHAT BUILD

WHAT WAS REMOVED
- Modular Chat package (modules/chat) deleted from this build.
- Internal Chat menu removed.
- Notifications menu removed.
- MD Chat Oversight menu removed.
- Chat alert module no longer imported or installed.
- Chat / notification DB counters no longer run on normal page renders.
- Chat unread lookup removed from dashboard reminder API.
- Old chat / notification / presence URLs are blocked and redirected to Dashboard.

WHAT IS PRESERVED
- Login & role security
- MD / GM / AM dashboards
- Employee Details
- Performance Analysis
- Accounts
- Lead Upload
- Lead Allocation
- My Leads
- Direct Single Lead
- Client Lead Profile
- Status / Ranking / Follow-up
- Enrollment / Payments
- Filing
- Management Reporting
- Report tools
- Security Settings / Activity Center
- Company Payment Accounts
- Daily Cash Book
- Existing database data

IMPORTANT
- No existing chat/history rows are deleted from the database.
- This package removes the active chat system from the application so it can be rebuilt later.
- No DB schema migration is required for this build.
